# SignBridge - Sign Language Communication System

## Project Description
SignBridge is a communication system designed to reduce communication barriers between sign-language users and people who do not understand sign language.

The system recognizes supported signs from camera, image, or video input and converts them into understandable text or speech. It may also support speech-to-text communication for two-way interaction.

## Project Modules
1. User Interface
2. Sign Input
3. Sign Recognition
4. Sign-to-Text Translation
5. Voice Communication
6. Additional Features
7. Results, Testing and Final Integration

## Objectives
- Recognize supported sign-language gestures.
- Convert recognized signs into text.
- Provide voice communication using text-to-speech.
- Improve communication between sign-language users and other people.
